当前已上线版本

World、Spots、进度、完成记录和提醒设置保存在设备本地。当前版本未集成广告或第三方统计 SDK。

创建 World 并请求 AI 建议时，输入的目标会通过 HTTPS 发送给 DeepSeek 处理。不能宣称所有数据都不离开设备。请不要输入敏感或保密内容。使用情况受 DeepSeek 隐私政策约束；Purrgress 不控制该服务商的数据保留策略。

正在准备的新版本

新版本将明确区分本地手动规划与用户主动选择的 AI 建议，通过服务端保管服务商密钥和核验额度。可选基础使用统计默认关闭，不包含目标正文、Spot 标题、联系人或广告 ID。以上不代表当前版本已经启用。

已准备的服务与保留期限

新版服务已部署在 Vercel，数据库使用 Neon；当前商店版本尚未接入。AI 生成仍关闭，待完成验证。配置的路径为 Vercel AI Gateway 转至 Baseten 运行 DeepSeek V4 Flash，没有其他模型或服务商自动后备，尚未通过成功生成验证。

新版将核验 Apple 签名而不保存原始签名收据，保留用于恢复和防重复奖励的账号、交易 HMAC、购买/退款状态及额度。这是可关联同一账号的假名化记录，不等于匿名。数据库不保存目标明文；目标 HMAC 用于请求重试校验，生成步骤加密缓存24小时。可选交互事件保留90天，可在设置中关闭分享并删除已上传事件；最少的购买和额度记录仍保留。清理每小时运行，实际物理删除最多再延迟一小时。托管方会为运行服务处理一般请求元数据，不用于跨应用广告追踪。

购买、网站与支持

Apple 处理付款，Purrgress 不获取银行卡信息。网站托管于 GitHub Pages，不使用广告像素或统计 Cookie，托管方可能按其隐私声明处理请求信息。GitHub 支持 issue公开可见，请勿上传私人目标、收据或账号信息。

删除 App 及其数据可能永久删除本地进度。完整英文数据说明区分当前版本与已准备的新版服务；新版发布前还需核验 App Store 问卷一致。
