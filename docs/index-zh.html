iPhone 与 iPad

从一直拖着的小事，开始一小步。

一个 World 是一个目标，一个 Spot 是一步。先做现实中的动作，再自己确认，让小猫和进度回应你。

当前如何收费？

当前上线版本是付费下载，美区价格 $19.99，安装前由 App Store 收费，没有已实现的自动续费订阅。

正在准备的新版本计划让用户免费体验第一个 World，最多 10 个 Spots；之后以美区 $29.99 一次解锁后续本地核心功能。这个新版本尚未上线，不能把它当作当前可用报价。老付费用户会保留已购核心权益。

如何开始？

  1. 选择一个具体目标，例如清理桌面的一角。
  2. 把第一步改小，例如把一个杯子放进水槽。
  3. 完成动作后自己确认，小猫向前，进度保存在设备上。

隐私与支持

进度保存在本地；当前版本请求 AI 建议时会把输入的目标发送给 DeepSeek。查看中文隐私说明。支持入口是公开 GitHub issue，请勿提交私人目标、收据或账号信息。
